Progressive Web App

Install FlowPomodoro on any device.

Enjoy offline focus sessions, lightning-fast load times, and a native desktop & mobile app experience without downloading from an app store.

Chrome & Edge (Desktop)

Run FlowPomodoro in a dedicated desktop window with native OS shortcut support.

  • Open FlowPomodoro in Chrome/Edge
  • Click the install icon (⊕) in the URL address bar
  • Click Install to add to desktop

iOS & iPadOS (Safari)

Add FlowPomodoro to your home screen for full-screen distraction-free timer sessions.

  • Open flowpomodoro.xyz in Safari
  • Tap the Share button (box with arrow)
  • Select Add to Home Screen

Android (Chrome)

Get instant access from your Android home screen with offline timer capability.

  • Open flowpomodoro.xyz in Chrome
  • Tap the three dots menu (⋮)
  • Tap Install App or Add to Home screen
